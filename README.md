# Versioner
Check your roblox system's version with ease.

# How to use Versioner:

1. Download the latest version of Versioner.
2. Drag the file into studio,
3. Place wherever,
4. Copy:
```lua
local Versioner = require(path.to.Versioner)
Versioner.CheckVersion(CurrentVersionHere, GithubUrlHere)
```
5. Paste the code into a script and fill out the relevant info required.
